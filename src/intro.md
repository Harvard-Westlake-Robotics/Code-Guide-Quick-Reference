# Intro

Hello. There’s three reasons why you’re here. Either you are here because you’re a new coder, a coder who forgot what they’re doing, or a member of another subteam who needs to figure out how some code works. In any case, welcome to the documentation! Feel free to use the document headings menu on the left to jump around the documentation.

**For new coders**, welcome to the coding team! If you’ve never coded on a scale like this before, know that coding is hard. This documentation is not really a documentation as much as it is a guide to everything you will need to know to start out. We suggest that you don’t read the entire guide at once (who wants to read 50 pages of this?), but rather tackle each section as it occurs during your time in the team. Additionally, we encourage you to learn from old code, especially code written in last year’s competition season. There’s also no shame in copying code, but try to understand at least what it is doing because you may need to explain it(or debug it) later. Finally, don’t worry if you don’t understand a lot now, you’ll learn a lot over time. 

**For members of other subteams**, this documentation will serve you if you know what you’re getting out of it. This won’t explain every line of code, but it will explain the big ideas and functions behind many of the files and code written in the codebase.

And now, please enjoy around 50 pages of walls of text and pictures.
