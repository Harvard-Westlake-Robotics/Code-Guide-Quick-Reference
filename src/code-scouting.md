# “Code Scouting”

During a competition, if you are a newer code team member, do not have any work, and are banned from seeing the codetop, you may be forced to “code scout”. Yay!  
	“Code scouting” is the exciting art of visiting every team we will be allianced with in a tournament and **making sure their autons and code work before the actual pit scouts and strategy team get there.** In games where simple tasks during the autonomous period can help you gain ranking points (eg. getting off the line in Reefscape) code scouts must also give all teams we are alliance with an auton that executes this simple task.

## How to Code Scout
	There are many different ways to organize the teams we are allianced with in order to visit them all. You should use whatever method is easier for you to keep track of. You can find the teams using Blue Alliance and also usually find a map of the pits by clicking on a team in the tournament in Blue Alliance and clicking on the link to see their place in Nexus. If you are code scouting with someone else, you may send them the autos of the teams you have already code scouted to keep track of who you have and haven’t done. If (real) scouting is an issue, get Data Science to give you and your code scouting buddy alternating scouting shifts so that at least one of you can be in the pits at all times.

## When to Code Scout
	It is important to have visited all teams we are alliance with at least once **during the first day of a competition (Saturday)**. On the second day, you must quickly revisit all teams that you still have qualifications with to make sure that their code still functions and solve any new issues that may have arisen since you last visited them. Even when you believe you have finished with code scouting, be prepared to help any teams that approach 1148 with a code issue. You can never be “done with code scouting”. Rather, code scouting must be done with you. 

## What to Say to Other Teams (aka Why to Code Scout)
	Begin by stating that you are from 1148 and you are there because you are allied with them in a match later in the tournament. First, say you are a coder (so they do not think you are from strategy or pit scouting) and ask them what autos they already have. If they have autos, take note of them somewhere and eventually send this information to your glorious code lead. **If they do not have autos, write them a simple auton.** After the autos, ask the team’s coder if they have any code issues, and help fix all of them no matter how complex they seem. In general, **you must treat other teams with gracious professionalism**. Before leaving, remind the team that they may always ask the people in the 1148 pit for help if any code problem occurs. Remember that, although it is good to collect data on their autons, pit scouting already does that. **Code scouting is mainly an Impact activity that aims to fix all code issues our alliance-mates may have.** Teams coming to our pit to ask for your help after you have visited them is a very important part of this process and can even help in alliance selection. One other perk of code scouting is that you get to know the other teams’ coders and can even learn from them. If our code has an issue, you may want to ask someone you’ve code scouted for help if they were particularly skilled with the subject of the problem. The work you put into code scouting will be put back into you.
